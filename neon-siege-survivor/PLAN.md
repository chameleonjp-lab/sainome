# Neon Siege: Survivor — 制作計画

## 対象

独自IPとして制作する、ブラウザで動く見下ろし型3Dサバイバルアクション。敵の群れを自動攻撃で処理し、経験値取得と三択の強化選択を重ね、制限時間まで生存することが目的。

## リスクスライス

| 優先度 | 検証対象 | 合格条件 |
|---|---|---|
| 高 | Babylon.jsのライフサイクルと操作 | 画面サイズ変更後も1つのキャンバスで移動・描画が継続する。 |
| 高 | 敵スポーン／追跡／接触ダメージ | 複数の敵が画面外から出現し、プレイヤーへ追従して体力を減らす。 |
| 高 | 自動攻撃と経験値ループ | 最寄り敵への自動射撃、撃破、ジェム吸引、経験値増加、レベルアップが一巡する。 |
| 中 | 三択の強化選択 | 画面を止めて成長を選択でき、再開後に武器または能力値へ反映される。 |
| 中 | 時間経過と難易度上昇 | タイマー、残敵圧、敵体力・発生量の増加がHUDと戦場の双方で確認できる。 |
| 低 | デモ自動操作 | `?demo` で実プレイらしい戦闘状況を再現し、画面検証に利用できる。 |

## 完了基準

1. キーボードまたは画面上の仮想スティックで移動できる。
2. 敵、弾丸、経験値ジェム、プレイヤーが同一の3Dアリーナで明瞭に見える。
3. 成長選択、被弾、ゲームオーバー、再出撃が実行できる。
4. デスクトップとモバイル幅でHUDが読み取れる。
5. `pnpm check` が成功し、代表画面の確認で重大な表示不良がない。
