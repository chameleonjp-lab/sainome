# Neon Siege: Survivor — 新規30攻撃モジュール案

## 設計前提

本案の30種は、現在の初期装備である **Rail Pulse**、**Shard Array**、**Arc Sentries** とは別枠の「レベル10以降に選べる新規モジュール」です。各モジュールは取得時に第1段階となり、同じモジュールを再取得することで第2・第3段階へ強化されます。

> 役割の重複を避けるため、直接攻撃20種、防御5種、設置3種、状態異常2種に固定します。すべてが敵へ働きかける戦闘モジュールですが、防御枠は生存と反撃のための能動的な攻撃補助として設計します。

| 区分 | 種数 | 設計意図 |
|---|---:|---|
| 直接攻撃 | 20 | 射線、範囲、追尾、近接、連鎖に明確な使い分けを与える。 |
| 防御 | 5 | 被弾軽減だけで終わらず、反撃や接近拒否へ変換する。 |
| 設置 | 3 | 移動経路・安全地帯・敵の誘導を生む。 |
| 状態異常 | 2 | 敵群を弱体化し、ほかの攻撃との相乗効果を作る。 |

## 解放・ランダム三択の仕様案

レベル10に到達した時点から、**5レベルごと**に「戦術モジュール選択」を発生させます。対象レベルは `10 / 15 / 20 / …` です。各回に表示する3択は、未取得モジュールの第1段階と、取得済みモジュールの未到達段階から**重複なしでランダム抽選**します。

| ルール | 仕様案 |
|---|---|
| 抽選母集団 | 未取得の30種 + 取得済みかつ第3段階未満のモジュール。 |
| 表示数 | 常に異なる3択。候補が3未満なら、所持済みモジュールの強化案で補完。 |
| 取得上限 | 同時所持は6モジュールまでを推奨。上限到達後は所持モジュールの第2・第3段階のみを抽選。 |
| 第1段階 | モジュールの基本挙動を解放する。 |
| 第2段階 | 数・範囲・頻度・射程など、主性能を伸ばす。 |
| 第3段階 | 挙動変化または他モジュールと連動する「完成形」にする。 |
| 既存装備 | Rail Pulse / Shard Array / Arc Sentries は初期装備として別枠扱い。必要なら後で30種プールへ編入できる。 |

## 実装優先度案

最初の実装では、射出・範囲・設置・防御・状態異常を1つずつ揃えると、三択の面白さを最短で検証できます。第1弾は **Vector Lance / Nova Ring / Mirage Drone / Sentry Pylon / Reactive Plating / Cryo Lock** の6種を推奨します。第2弾で物理挙動を使う **Rico Burst / Flux Boomerang / Singularity Shot / Decoy Beacon** を追加し、第3弾で残りを投入します。
