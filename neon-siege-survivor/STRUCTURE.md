# Neon Siege: Survivor — 構成

## 実行時の責務

| モジュール | 責務 |
|---|---|
| `components/GameCanvas.tsx` | Babylonエンジンの一度だけの初期化、DOM HUDの表示、ゲームハンドルへの入力・選択命令の橋渡し。 |
| `game/scene.ts` | シーン、カメラ、光源、アリーナ、生成テクスチャ、`GameWorld` の組み立てと明示的な破棄。 |
| `game/GameWorld.ts` | 移動、スポーン、敵追跡、弾丸、経験値、成長、時間、ゲームオーバーを所有するフレームワーク非依存のゲームループ。 |
| `game/types.ts` | UIスナップショットとアップグレード選択肢の共有契約。 |
| `game/assets.ts` | Webストレージに置いた生成画像のURLを集約する。 |

## 状態遷移

`playing` の間は入力・敵・弾丸・経験値を更新する。経験値がしきい値に達すると `upgrade` に移り、DOM上の三択を選ぶまで3D世界の更新を止める。体力が0になると `gameover` になり、`再出撃` で全エンティティと数値を初期化して `playing` に戻る。

## 資産契約

大きな画像はプロジェクトツリーに配置せず、WebストレージURLだけを `assets.ts` に定義する。床面画像は繰り返しテクスチャ、敵用画像は敵ボディの発光テクスチャ、ロゴはDOM HUDの記章として利用する。生成画像が読み込み中でも、手続きメッシュと基本色でゲームが成立する。
