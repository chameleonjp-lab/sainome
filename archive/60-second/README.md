# 60秒版アーカイブ

このディレクトリは、旧60秒版の実装と生成ルールを参照用に保存しています。実装が単独で参照できるよう、当時のサイコロ面とモード定義も同じ場所へ保存しています。
`index.html` と `js/main.js` からは読み込まれません。新規プレイは300秒モードだけです。

旧60秒の途中保存・未送信ランキング記録は、互換性のため削除・変換せず元のモードとして保全します。
アーカイブの生成ルールを確認する場合は、リポジトリのルートから `node --test archive/60-second/spawn-rules.test.legacy.js` を実行します。通常のCI対象ではありません。
このアーカイブのコードを実行経路へ戻す場合は、現行の保存契約・ランキング契約・受入試験を見直してください。
