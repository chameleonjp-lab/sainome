# 第11工程 実機受入記録

このファイルは、公開候補版を実機で確認した結果を残すためのテンプレートです。空欄や「未実施」は合格として扱いません。実施後は候補版のSHAと配備URLを固定したまま、Issue #24へ記録へのリンクを追加してください。

## 記録ルール

- すべての行で同じ候補版SHA、同じ配備URL、実施時の端末・OS・ブラウザ版を記録する。
- WebGL強制消失は診断用URLのパネルから10回実行し、復元、再生成、ホーム退避のいずれになったかを記録する。
- 診断値は各回の強制消失前と復元または退避後に記録する。描画予約、サイコロ数、シーン内物体数、GPU形状、テクスチャ、アニメーション予約が周回ごとに増え続けないことを確認する。
- 1台につき3回連続で全項目を合格するまで、その端末の判定を合格にしない。3台すべてが合格するまで、第11工程全体を完了にしない。
- 実機で確認できない項目を自動テストの成功だけで補完しない。ランキング受付とゲーム公開状態は、受入完了を別途判断するまで停止状態を維持する。
